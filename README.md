# coach-bot — телеграм-коуч Василия

Второй канал того же коуча, что живёт в Claude Code. Голос — основной вход:
наговорил → расшифровалось → коуч понял, разложил дела по Todoist и записал
значимое в общую память.

Бот: [@vefmv_gtd_bot](https://t.me/vefmv_gtd_bot) · хостинг: Bronto, контейнер `coach-bot`.

## Из чего состоит

| Файл | За что отвечает |
|---|---|
| `src/main.py` | Телеграм: поллинг, голос, два пинга в день, ночная выжимка |
| `src/engine.py` | **Движок**: Claude Agent SDK, непрерывная сессия, инструменты |
| `src/sessions.py` | Закладка разговора — какой `session_id` продолжать |
| `src/todoist.py` | Инструменты Todoist (REST v1) с пометкой авторства |
| `src/voice.py` | Расшифровка голосовых (Whisper) |
| `src/brain.py` | Синхронизация памяти через git |
| `src/digest.py` | Ночная выжимка: день → неделя → месяц |
| `src/tidy_history.py` | Ночная причёска истории: день → один осмысленный коммит |
| `prompts/coach.md` | Роль коуча |

Движок намеренно отделён от телеграм-слоя: когда появится второй боевой
потребитель Claude на сервере (проверка домашек, новости, сайт), из `engine.py`
вырастет общий агент-шлюз, а бот станет его первым клиентом.

## Память: три слоя

1. **Разговор** — сессия SDK, файл на диске. Переживает паузы и рестарты.
2. **Выжимки** — каждую ночь в 03:00 день перечитывается и складывается в
   `память/журнал/выжимки/дни/`, после чего разговор начинается с чистого листа.
   Воскресной ночью дни сворачиваются в неделю, первого числа недели — в месяц.
   Так контекст не пухнет до предела, а память за месяцы влезает в любой разговор.
3. **Мозг** — папка `память/` из репозитория `coach-brain`, общая с Claude Code.

## Причёска истории (тоже ночью)

Сторож на макбуке подписывает коммиты машинно («Автосохранение мозга: 21.07 22:36») — иначе никак: он срабатывает на каждое сохранение файла и звать модель не может. Ночью, сразу после выжимки, `tidy_history.py` сворачивает день в один коммит и подписывает его по-человечески, глядя на реальный diff. Осмысленные заголовки дня переносятся в тело коммита.

История переписывается — значит осторожность важнее красоты:

- только когда рабочее дерево чистое и локальная история совпадает с удалённой;
- `--force-with-lease`, чтобы не затереть чужой push;
- после свёртки дерево сверяется с исходным: изменилось хоть на байт — откат;
- сторож на маке принимает свёрнутую историю по тому же признаку (деревья совпали), а при настоящем расхождении данные не трогает и пишет владельцу в Telegram.

## Развернуть

```bash
git clone git@github.com:vefmvai/coach-bot.git /opt/apps/coach-bot
cd /opt/apps/coach-bot
cp .env.example .env && vim .env          # токены
git clone git@github.com:vefmvai/coach-brain.git data/brain
docker compose up -d --build
docker compose logs -f
```

Почему поллинг, а не вебхуки: РКН режет входящие вебхуки Telegram, бот сам
ходит за обновлениями.

## Обслуживание

```bash
docker compose logs -f --tail=100    # что происходит
docker compose restart               # разговор не теряется — session_id на диске
docker compose up -d --build         # выкатить изменения
```

Команды в чате: `/start` — проверка связи, `/new` — начать разговор с чистого
листа (память о Василии при этом остаётся).
