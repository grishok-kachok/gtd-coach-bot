# coach-bot — телеграм-коуч Василия

Второй канал того же коуча, что живёт в Claude Code. Голос — основной вход:
наговорил → расшифровалось → коуч понял, разложил дела по Todoist и записал
значимое в общую память.

Бот: [@vefmv_gtd_bot](https://t.me/vefmv_gtd_bot) · хостинг: Bronto, контейнер `coach-bot`.

## Из чего состоит

| Файл | За что отвечает |
|---|---|
| `src/main.py` | Телеграм: поллинг, голос, два пинга в день, ночная выжимка |
| `src/engine.py` | **Движок**: Claude Agent SDK, непрерывная сессия, инструменты |
| `src/sessions.py` | Закладка разговора — какой `session_id` продолжать |
| `src/todoist.py` | Инструменты Todoist — обёртки над ядром `todoist_mcp` |
| `src/voice.py` | Расшифровка голосовых: Groq, при осечке — OpenAI |
| `src/retry.py` | Повтор сетевых операций: мост моргнул — не потеряли голосовое |
| `src/brain.py` | Синхронизация памяти через git |
| `src/digest.py` | Ночная выжимка: день из сырья, неделя и месяц — из дней |
| `src/tidy_history.py` | Ночная причёска истории: день → один осмысленный коммит |

Роли коуча в этом репозитории нет: конституция, правила памяти и навыки живут
в отдельном плагине [`gtd-coach`](https://github.com/vefmvai/gtd-coach) и приезжают
сюда смонтированным клоном (`/plugin`, только на чтение). Так их читают обе
стороны — и бот, и сессия в мастерской, — а не два разошедшихся файла.

Движок намеренно отделён от телеграм-слоя: когда появится второй боевой
потребитель Claude на сервере (проверка домашек, новости, сайт), из `engine.py`
вырастет общий агент-шлюз, а бот станет его первым клиентом.

## Путь голосового

Три шага, и каждый идёт наружу через Xray-мост: забрать ссылку на файл у
Telegram → скачать аудио → расшифровать. Мост иногда моргает (27.07.2026
голосовое потерялось на первом шаге — `ReadTimeout` в `get_file`), поэтому
каждый шаг повторяется до 10 раз с нарастающей паузой (`src/retry.py`).
Повторяются только сбои, которые чинятся сами: таймауты, обрывы, 429, 5xx.
Отказ по существу (битый `file_id`, неверный ключ) вылетает сразу — крутить
его бессмысленно.

Расшифровка вдобавок держит два сервиса: **Groq** (бесплатный тир) и на любой
его осечке сразу **OpenAI** — одна попытка основному, остальные девять
запасному. Владелец видит происходящее: с третьего повтора бот пишет «связь
шалит», при переходе на запасной — «Groq не отвечает, расшифровываю через
OpenAI». Если не вышло совсем — сообщение с числом попыток и причиной.

## Память: три слоя

1. **Разговор** — сессия SDK, файл на диске. Переживает паузы и рестарты.
2. **Выжимки** — каждую ночь в 03:00 день перечитывается и складывается в
   `память/журнал/выжимки/дни/`, после чего разговор начинается с чистого листа.
   Воскресной ночью собирается неделя, первого числа — прошлый месяц. И неделя,
   и месяц собираются **из дневных выжимок в базе**, а не из уровня выше и не
   из сырья: месяц из недель был бы пересказом пересказа, а месяц сырья — около
   492 000 токенов, он просто не влезет.

   В начало нового разговора подставляется **ровно 15 кусков всегда**: 3 месяца,
   5 недель, 7 дней (`WINDOW` в `src/archive.py`). Постоянное количество делает
   размер памяти умножением, известным заранее, — резать по живому не нужно
   никогда. Журнал в мозге держится в том же окне: файлы старше него удаляются,
   тексты остаются в базе и в истории git.
3. **Мозг** — папка `память/` из репозитория `gtd-coach-brain`. Единственный
   экземпляр живёт на сервере: разговаривают с коучем только через телеграм.

## Причёска истории (тоже ночью)

Машинные коммиты («досохранение») делает серверный сторож `sync-coach-brain.sh`: он срабатывает по расписанию и звать модель не может. Ночью, сразу после выжимки, `tidy_history.py` сворачивает день в один коммит и подписывает его по-человечески, глядя на реальный diff. Осмысленные заголовки дня переносятся в тело коммита.

История переписывается — значит осторожность важнее красоты:

- только когда рабочее дерево чистое и локальная история совпадает с удалённой;
- `--force-with-lease`, чтобы не затереть чужой push;
- после свёртки дерево сверяется с исходным: изменилось хоть на байт — откат;
- сторож на маке принимает свёрнутую историю по тому же признаку (деревья совпали), а при настоящем расхождении данные не трогает и пишет владельцу в Telegram.

## Развернуть

```bash
git clone git@github.com:vefmvai/gtd-coach-bot.git /opt/apps/coach-bot
cd /opt/apps/coach-bot
cp .env.example .env && vim .env          # токены
git clone git@github.com:vefmvai/gtd-coach-brain.git data/brain
docker compose up -d --build
docker compose logs -f
```

Почему поллинг, а не вебхуки: РКН режет входящие вебхуки Telegram, бот сам
ходит за обновлениями.

## Проверить ротацию памяти

Ротацию нельзя проверить живым прогоном: одна проверка стоит суток ожидания,
а «месяц в конце месяца» — тридцати. Поэтому год жизни бота проигрывается
на синтетических датах за секунду, без вызова модели.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest
.venv/bin/pytest tests/ -q
```

Тесты стерегут ровно то, что было сломано до 31.07.2026: постоянный размер
окна, отсутствие дырок в покрытии, ISO-ключ недели, календарные границы месяца
и сборку уровней из базы, а не из файлов.

## Обслуживание

Код правится **только на ноутбуке** и приезжает на сервер через GitHub:
ноутбук → `git push` → на сервере `git pull`. Клон `/opt/apps/coach-bot` —
цель выкатки, а не источник правды: его deploy-ключ read-only, а хук `pre-commit`
там отклоняет коммиты. Так на сервере физически не может завестись версия кода,
которой нет больше нигде.

```bash
docker compose logs -f --tail=100    # что происходит
docker compose restart               # разговор не теряется — session_id на диске
git pull && /opt/infra/scripts/host/with-build-lock.sh docker compose up -d --build
```

Сборку — только через `with-build-lock.sh`: две параллельные сборки на этом
хосте роняли демон Docker.

### Здоровье

`docker ps` показывает у контейнера `healthy` / `unhealthy`. Проверка —
`src/healthcheck.py`: свежесть пульса главного цикла (`/tmp/coach-heartbeat`,
обновляется раз в минуту) плюс живой ответ Telegram через прокси. Красный статус
сам доезжает до владельца — хостовый сторож `check-containers.sh` шлёт алерт в
Telegram. Посмотреть причину:

```bash
docker inspect --format '{{json .State.Health}}' coach-bot | python3 -m json.tool
```

Команды в чате: `/start` — проверка связи, `/new` — начать разговор с чистого
листа (память о Василии при этом остаётся).
